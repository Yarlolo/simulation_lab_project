# Моделирование систем массового обслуживания и игр

В проекте реализованы две небольшие модели на Python:

1. Модель работы банка с несколькими окнами обслуживания.
2. Игровая модель «Камень, ножницы, бумага», в которой два игрока используют разные стратегии.

Основная задача проекта — посмотреть, как ведут себя такие системы при разных условиях, и сравнить полученные результаты.

## 1. Модель банка

В первой части рассматривается работа условного банка. Клиенты приходят с определённой интенсивностью, проходят регистрацию и попадают в общую очередь. Когда одно из окон освобождается, следующий клиент начинает обслуживание.

В модели учитываются:
- интенсивность поступления клиентов;
- среднее время обслуживания;
- количество работающих окон;
- максимальное время ожидания в очереди;
- клиенты, которые не стали дожидаться обслуживания.

Для наглядности в приложении есть схема банка и анимация движения клиентов. Можно посмотреть, как формируется очередь, какие окна заняты и как клиенты проходят через систему.

Также можно менять параметры моделирования и смотреть, как это влияет на время ожидания и загрузку окон.

## 2. Игровая модель

Во второй части реализована игра «Камень, ножницы, бумага».

Для сравнения используются четыре стратегии:

- **Случайная** — каждый ход выбирается случайным образом.
- **Постоянная** — игрок всегда выбирает один и тот же вариант.
- **Циклическая** — ходы повторяются в определённом порядке.
- **Адаптивная** — игрок анализирует предыдущие ходы соперника и пытается подобрать ответ на наиболее часто встречающийся вариант.

Можно выбрать стратегии двух игроков, задать количество раундов и посмотреть итог игры.

По результатам отображаются победы, поражения и ничьи. Это позволяет сравнить стратегии между собой и посмотреть, насколько хорошо они работают против разных соперников.

## 3. Используемые библиотеки

В проекте используются:

- **Python** — основной язык программирования.
- **Streamlit** — интерфейс приложения.
- **SimPy** — моделирование процессов обслуживания.
- **NetworkX** — построение графовой модели банка.

## 4. Запуск проекта

Для запуска понадобится Python версии 3.10 или новее.

Сначала нужно скачать проект и перейти в его папку:

```bash
cd simulation_lab
```

Затем установить необходимые библиотеки:

```bash
pip install -r requirements.txt
```

После установки запустить приложение:

```bash
streamlit run app.py
```

После этого приложение откроется в браузере. Если оно не открылось автоматически, нужно перейти по адресу, который появится в терминале (обычно это `http://localhost:8501`).
