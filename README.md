# Simulation Lab

Минималистичное Streamlit-приложение для демонстрации двух имитационных моделей:
1. Графовая модель банка с очередью и несколькими каналами обслуживания.
2. Повторяющаяся игра «Камень, ножницы, бумага» с несколькими стратегиями агентов.

## Локальный запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## Публикация

1. Создайте репозиторий GitHub и загрузите содержимое этой папки.
2. Откройте https://share.streamlit.io/
3. Войдите через GitHub, выберите репозиторий, ветку `main` и файл `app.py`.
4. Нажмите Deploy. После успешной публикации получите публичную ссылку.

## Примечания к моделям

- Модель банка: пуассоновский поток поступления, экспоненциальное время обслуживания, единая очередь, ограниченное число окон и ограниченное терпение клиентов.
- Игровая модель: одновременный выбор ходов, нулевая сумма выигрышей, четыре эвристические стратегии.
- Для исследовательских выводов рекомендуется повторять каждый сценарий с несколькими seed и сравнивать средние значения и разброс.
