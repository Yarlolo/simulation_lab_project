# Simulation Lab

Минималистичное Streamlit-приложение для демонстрации двух имитационных моделей:
1. Графовая модель банка с очередью и несколькими каналами обслуживания.
2. Повторяющаяся игра «Камень, ножницы, бумага» с несколькими стратегиями агентов.

## Локальный запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## Примечания к моделям

- Модель банка: пуассоновский поток поступления, экспоненциальное время обслуживания, единая очередь, ограниченное число окон и ограниченное терпение клиентов. В интерфейсе доступны схема графа, динамика очереди и занятости окон, распределение ожидания, загрузка окон и сравнение конфигураций.
- Игровая модель: одновременный выбор ходов, нулевая сумма выигрышей, шесть стратегий: случайная, постоянная, циклическая, частотная, марковская и смешанная. Турнир сравнивает все пары стратегий.
- Для исследовательских выводов рекомендуется повторять каждый сценарий с несколькими seed и сравнивать средние значения и разброс.
